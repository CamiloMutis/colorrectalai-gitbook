Plan integrador según la Guía PMBOK: reúne los planes subsidiarios y las líneas base de alcance, tiempo, costo y calidad en un solo documento.

## Contenido

* Acta de constitución del proyecto
* Recursos y roles
* Plan de comunicaciones
* Gestión de riesgos
* Gestión de interesados
* Monitoreo y control (alcance, cronograma, calidad, riesgos, cambios)
* Plan de cierre (validación, documentación final, lecciones aprendidas, aceptación)

## Recursos y roles

Director/docente, líder, investigador, desarrollador de IA, desarrollador de software, diseñador y responsable de pruebas. Ver [Matriz de interesados](../inicio/matriz-interesados.md).

## Comunicaciones

* Reunión semanal del equipo (minuta en el formato WEEK de TSP).
* Reuniones con el docente.
* Actas, correo institucional y repositorio.
* Revisión formal de entregables antes de cargarlos en Moodle.

## Riesgos

Riesgos R01 a R08 del Acta de Constitución (sección 3.8), revisados cada semana en el formato ITL (probabilidad e impacto de 1 a 5; exposición = P × I).

| ID | Riesgo | Estado |
| --- | --- | --- |
| R01 | Dataset insuficiente o con licencia que no permita su uso académico | Abierto |
| R02 | Recursos computacionales o herramientas insuficientes dentro del presupuesto académico | Abierto |
| R03 | Fuga de información entre entrenamiento y prueba | Abierto |
| R04 | Baja disponibilidad del equipo durante el semestre | Abierto |
| R05 | Dificultades para integrar el modelo con la API y la interfaz web | Abierto |
| R06 | Que el resultado se interprete como clínicamente válido o que el módulo se presente como dispositivo médico | Abierto |
| R07 | Problema de generalización, sesgo o confianza mal calibrada del modelo | Abierto |
| R08 | Documentación insuficiente para reproducir los experimentos | Abierto |

Otros riesgos a considerar: datos desbalanceados, bajo rendimiento, sobreajuste, retrasos y cambios de requisitos.

Estrategias de respuesta: **Evitar / Aceptar / Reducir / Transferir** (amenazas) y **Explotar / Aceptar / Mejorar / Compartir** (oportunidades).
