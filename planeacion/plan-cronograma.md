## Reglas de control

| Regla | Valor |
| --- | --- |
| Línea base | Cronograma aprobado el 18 oct 2026 (hito 007) |
| Indicador | SPI = VG acumulado / VP acumulado |
| Umbral | SPI ≥ 0,90 (desviación ≤ 10 %) |
| Desviación una semana | Se reasigna trabajo |
| Desviación dos semanas | Se replanean las tareas y se registra una solicitud de cambio |
| Retraso de un hito > 10 % | Se comunica al Propietario del Proyecto |
| Cambios a la línea base | Procedimiento ECP → DP → PP |
